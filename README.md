# Информационная система автосервиса

> Курсовая работа по дисциплине «Конструирование программного обеспечения»  
> Студент: Потапов Н.С., группа ПИБд-41

## 📋 Описание

Приложение для автоматизации работы автосервиса. Позволяет управлять заявками на обслуживание, клиентами, автомобилями, услугами и запчастями, а также формировать чеки выполненных работ.

## 🏗️ Архитектура

- **Frontend**: Windows Forms (.NET 8)
- **Backend**: Встроенный (без отдельного API)
- **База данных**: PostgreSQL 15
- **ORM**: Entity Framework Core 8

## 🚀 Быстрый старт

### 1. Установка Docker

Скачайте и установите Docker Desktop:
- [Docker Desktop для Windows](https://www.docker.com/products/docker-desktop/)

### 2. Запуск базы данных

Откройте **bash** и выполните:

```bash
cd /e/code/kpo-coursework-autoservice
docker compose up -d
```

Проверьте статус:
```bash
docker compose ps
```

Просмотр логов (при необходимости):
```bash
docker compose logs postgres
```

**Пароли по умолчанию:**
- Пользователь БД: `postgres`
- Пароль БД: `postgres`

### 3. Запуск приложения

В Visual Studio:
- Откройте `AutoServiceSystem.sln`
- Нажмите F5

Или через командную строку:
```bash
cd AutoServiceSystem
dotnet run --project View
```

## 📊 Сущности системы

| Сущность | Таблица | Описание |
|----------|---------|----------|
| **User** | `users` | Пользователи системы (администратор, менеджер) |
| **Client** | `clients` | Клиенты автосервиса (физ. и юр. лица) |
| **Car** | `cars` | Автомобили клиентов |
| **Service** | `services` | Услуги (справочник) |
| **Part** | `parts` | Запчасти (справочник) |
| **Order** | `orders` | Заявка на обслуживание (заказ-наряд) |
| **OrderService** | `order_services` | Услуги в заявке |
| **OrderPart** | `order_parts` | Запчасти в заявке |
| **Check** | `checks` | Чек (выполненная заявка) |

## 🔐 Роли пользователей

### Администратор (`admin`)
- ✅ Управление пользователями (создание менеджеров)
- ✅ Управление справочниками (услуги, запчасти)
- ✅ Просмотр всех данных системы

### Менеджер (`manager`)
- ✅ Управление клиентами и автомобилями
- ✅ Создание и редактирование заявок
- ✅ Выбор услуг и запчастей для заявок
- ✅ Формирование чеков
- ✅ Просмотр графика занятости мастеров

## 🛠️ Разработка

### Требования
- .NET 8 SDK
- Docker Desktop
- Visual Studio 2022 (опционально)

### Сборка

```bash
cd AutoServiceSystem
dotnet build
```

### Пересоздание БД

При изменении структуры БД:

```bash
cd /e/code/kpo-coursework-autoservice
docker compose down -v
docker compose up -d
```

## 📝 Примечания

- Мастер не имеет учётной записи в системе (указывается в заявке)
- Пароли хэшируются алгоритмом BCrypt
- Заявки имеют статусы: `Ожидает`, `В работе`, `Выполнена`, `Просрочена`, `Отменена`
- Чек создаётся из выполненной заявки
